# 標準仮想PC 自動起動ツール

Citrix（rpc.soka.jp）の **「標準仮想PC」をダブルクリック1回で起動** するための便利ツールです。
これまで手作業で行っていた次の流れを自動化します。

1. ブラウザで `rpc.soka.jp`（Citrix StoreFront）を開く
2. お気に入りの **「標準仮想PC」** をクリック
3. ダウンロードされた **`.ica` ファイル** を開く（Citrix Workspace が起動）
4. Windows ログイン画面で **パスワードを入力** してログイン

Mac・Windows の両方に対応しています。

---

## いちばん大事なこと（安全性）

- パスワードは **OSの安全な保管庫**（Mac＝キーチェーン / Windows＝資格情報マネージャー）に保存します。
- スクリプトや設定ファイル、配布物の中に **パスワードを書き込むことはありません**。
- 画面の位置や解像度の違いに強い作りにしています（座標の決め打ちをしていません）。

---

## 使い方（配布された方向け）

### 事前に必要なもの

- **Citrix Workspace アプリ**（`.ica` を開くために必要。普段お使いのものでOK）
- **Python 3**（無い場合は <https://www.python.org> からインストール。
  Windows ではインストール時に「Add Python to PATH」にチェック）
- ブラウザで `rpc.soka.jp` に **ログインできる状態**（普段ログインに使っているブラウザでOK）

### STEP 1. 初期設定（最初に一度だけ）

| OS | ダブルクリックするファイル |
|----|------------------------------|
| Mac | `初期設定.command` |
| Windows | `初期設定.bat` |

実行すると、画面の案内に沿って次を行います。

1. **パスワードの登録**：ユーザー名とパスワードを入力 → OSの保管庫に安全に保存
2. **タイル画像の登録**：画面に表示された「標準仮想PC」タイルを
   スクリーンショットで撮り、`templates` フォルダに **`tile.png`** という名前で保存
   - Mac：`Command + Shift + 4` で範囲選択して撮影
   - Windows：「切り取り & スケッチ（Snipping Tool）」で撮影
3. （任意）ログイン画面も撮って **`lock.png`** として保存すると、
   パスワード入力のタイミングがより正確になります

> **Mac の方は権限の許可が必要です**
> システム設定 →「プライバシーとセキュリティ」→
> 「**アクセシビリティ**」と「**画面収録**」に、起動に使うアプリ（ターミナル等）を追加してオンにしてください。
> 設定後はアプリを再起動してください。

### STEP 2. 起動（毎回これだけ）

| OS | ダブルクリックするファイル |
|----|------------------------------|
| Mac | `仮想PC起動.command` |
| Windows | `仮想PC起動.bat` |

あとは自動で StoreFront を開き、タイルをクリックし、`.ica` を開いて、
ログイン画面でパスワードを入力します。

> 途中で止めたいとき：マウスを **画面の左上の角** に勢いよく動かすと安全に中断できます（Mac/Windows共通）。

---

## うまく動かないとき

| 症状 | 対処 |
|------|------|
| 「タイルが見つかりません」 | ブラウザで rpc.soka.jp にログイン済みか確認。`tile.png` を撮り直す（初期設定を再実行） |
| `.ica` を開いてくれない | Citrix Workspace アプリがインストール済みか確認。ダウンロード先が標準の「ダウンロード」フォルダか確認 |
| パスワードが入力されない | `lock.png` を登録するか、`config.json` の `lock_screen_pre_delay`（待ち秒数）を増やす |
| Mac でクリックされない | 「アクセシビリティ」「画面収録」の許可を確認（上記） |
| パスワードを変更したい | もう一度「初期設定」を実行すると更新できます |

---

## 設定ファイル `config.json`（必要な人だけ）

| 項目 | 説明 |
|------|------|
| `store_url` | StoreFront の URL（既定: `https://rpc.soka.jp/`） |
| `resource_name` | 起動するリソース名（既定: `標準仮想PC`） |
| `image_confidence` | 画像認識の一致しきい値（0〜1、既定 0.8。誤検出時は上げる） |
| `type_password` | パスワード自動入力の ON/OFF |
| `lock_screen_pre_delay` | `lock.png` 未登録時にパスワード入力まで待つ秒数 |
| `timeouts` | 各ステップの待ち時間（秒） |

---

## 配布時の注意

- `templates/` 内のスクリーンショット（`*.png`）と `.venv/` は **配布物に含めません**
  （`.gitignore` で除外済み）。画像は各自が初期設定で撮影します。
- パスワードは各自の端末のOS保管庫にのみ保存されるため、共有されません。

---

## 仕組み（技術メモ）

- `launch_citrix.py` … 本体。`webbrowser` で StoreFront を開き、`pyautogui` の
  画像認識でタイルをクリック、ダウンロードフォルダの最新 `.ica` を OS 既定アプリで開き、
  ログイン画面でキーストロークによりパスワードを送信します。
- `setup_tool.py` … 初期設定。`keyring` でパスワードを OS 保管庫へ保存し、
  画像登録と権限設定を案内します。
- パスワード取得は `keyring.get_password(service, username)`、
  保存は `keyring.set_password(...)`。バックエンドは Mac=Keychain / Windows=Credential Manager が自動選択されます。

> より堅牢にしたい場合（将来の改善案）
> Windows では Citrix 公式の `SelfService.exe -qlaunch "標準仮想PC"` を使うと、
> ブラウザを介さず直接リソースを起動できます（Citrix Workspace にストアの
> アカウント登録が必要）。現状はMac/Windowsで操作を揃えるためブラウザ方式にしています。
